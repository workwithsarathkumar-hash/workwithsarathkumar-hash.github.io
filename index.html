Gesture Control

A hand-swipe tool built into Jarvis — Apple's Vision framework tracks my wrist through the webcam, no cloud, no MediaPipe (its native hand-tracking crashed hard on this Mac, so this runs on Apple's own on-device model instead). A swipe maps to a swappable "plug" — right now it switches between full-screen Spaces, the same as a trackpad gesture. I use it daily to flip between this site and the editor without touching the trackpad.
